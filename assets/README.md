# Visual assets

- `taylors-logo.png`: supplied school logo, used in its original red and black colours.
- `taylors-campus.webp`: campus buildings and lake photograph downloaded from the [official university website](https://university.taylors.edu.my/en/discover-us/about-taylors/vision-and-strategy.html).

Original photograph: [official image file](https://university.taylors.edu.my/content/dam/taylorsrevamp/university/discover-us/about-taylors/our-vision-for-the-future/banners/taylors-our-vision-for-the-future-banner-1920x860.png/jcr:content/renditions/cq5dam.web.1920.860.webp).

The app reads these files relative to its own directory. No network request or local computer path is required at runtime.
